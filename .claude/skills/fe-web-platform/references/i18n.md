# Internacjonalizacja (i18n) w interfejsie

Przeniesione z importu frontend-developer (`staff.md`, „i18n”), uzupełnione o API `Intl` i praktykę 2026.

## i18n vs l10n

- **i18n** — przygotowanie architektury: teksty poza kodem, formaty zależne od locale, układ gotowy na RTL i dłuższe
  napisy. Praca jednorazowa, architektoniczna.
- **l10n** — tłumaczenie i adaptacja treści dla rynku. Proces ciągły. Dobra i18n = nowy język bez zmiany kodu,
  tylko nowy zestaw tłumaczeń.

## Zasady

- **Komunikaty w formacie ICU MessageFormat** (FormatJS/`react-intl`, `i18next` z ICU, Angular `$localize`/i18n z
  ICU, Transloco) — z parametrami i liczbą mnogą w komunikacie, nie składane konkatenacją („Masz ” + n + „ plików”).
- **Liczba mnoga** zależy od języka: polski ma kategorie `one` (1), `few` (2–4, 22–24…, bez 12–14), `many` (0, 5–21,
  25…), `other` (ułamki). `Intl.PluralRules('pl').select(n)` zwraca kategorię — nie zakładaj „1 vs reszta”.
- **Formatowanie** zawsze przez `Intl`: `DateTimeFormat`, `NumberFormat` (waluty, jednostki, `compact`),
  `RelativeTimeFormat` („3 dni temu”), `ListFormat` („a, b i c”), `Collator` (sortowanie z polskimi znakami),
  `DisplayNames`, `Segmenter` (dzielenie tekstu na znaki/słowa — emoji, języki bez spacji). Strefy czasowe:
  `timeZone` w formatterze; w nowym kodzie `Temporal` tam, gdzie dostępne (lang-javascript).
- **Locale** z ustawień użytkownika / `navigator.languages` / nagłówka `Accept-Language`, zapisywane w URL
  (`/pl/…`) lub profilu; ustaw `<html lang>` i `dir`.
- **RTL** — nie tylko tekst, cały układ: CSS logical properties (`margin-inline-start`, `inset-inline-end`,
  `padding-block`) zamiast `left/right`, odwracanie ikon kierunkowych, `dir="auto"` dla treści od użytkownika (fe-css).
- **Długość tekstu** — niemiecki/fiński bywają o 30–40% dłuższe; nie projektuj na sztywną szerokość, testuj
  pseudolokalizacją.
- **SSR** — format zależny od locale/strefy liczony na serwerze musi zgadzać się z klientem (hydration mismatch —
  fe-architecture `.claude/skills/fe-architecture/references/rendering-models.md`).
- Nie tłumacz przez sklejanie fragmentów zdań ani nie wkładaj tekstu w obrazy; kontekst i opis dla tłumacza przy
  każdym kluczu.
